# Tasks
- Understand the project using this markdown file and the ``látványterv.png``
- **Main task:** Your main task will be to create a newspaper page that is inspired from pages like Telex. The main page features the title of the newspaper, a running title bar containing the newest news (max 5 days), and the news below (as it can be seen in the png).
- After understanding the project, run the **/grilling** command
# Constraints
- The page must contain a dark and light mode
- The pages color scheme must contain some combination of green and blue
- The page must run on a static GitHub Page website
- All code needs to run as client side javascript
- All pages will be written in markdown and would be parsed and inserted into a well crafted template by the client.
- The news articles could be clicked, optionally images could be added as cover images
- There should be a weather forecast in the top left corner, data supported by openmeteo free api (temperature, cloud coverage by icons, precipitation). All data should be pulled for the Hungarian Children's Railway (Budapest) Gyermekvasutas Otthon és Tábor.
- When clicking on the weather widget, an extended pop up window would display the forecast per station of the railway.
